- `worker_tick`: Der `pre-push`-Hook setzt vor `TEST_CMD` `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_PREFIX` und die übrigen `GIT_*`-Variablen zurück. Beim Push aus einem Worktree (Slots w1/w2) setzt git dort `GIT_DIR` auf `.git/worktrees/<name>`; die Tests liefen dadurch im echten Klon statt im `tmp_path`, der Push des Takts wurde trotz grüner Tests abgelehnt und hinterließ einen Fremdcommit im Branch (#212).
